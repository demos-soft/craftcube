CraftCube has been installed as release "{{ .Release.Name }}" in namespace "{{ .Release.Namespace }}".

1. Reach the app:
{{- if .Values.ingress.enabled }}
{{- range .Values.ingress.hosts }}
   http{{ if $.Values.ingress.tls }}s{{ end }}://{{ .host }}
{{- end }}
{{- else }}
   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "craftcube.fullname" . }} 8080:{{ .Values.service.port }}
   then open http://localhost:8080
{{- end }}

2. Log in with any account that exists on the IMAP server
   ({{ .Values.config.imap.host }}:{{ .Values.config.imap.port }}{{ if .Values.config.imap.ssl }} SSL{{ end }}).
   The first login auto-creates the CraftCube user row and a default identity.

3. Shared-mailbox mode: set config.perUserPasswords="0" and provide
   secret.imapAdminUser/imapAdminPass (or an existingSecret with the same keys).

Note: the database is SQLite on a RWO volume; keep replicaCount at 1 unless
the volume supports ReadWriteMany.
